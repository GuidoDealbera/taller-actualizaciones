# Actualizaciones

Acá se publican las versiones del sistema de gestión del taller: los
instaladores y los archivos que usa la actualización automática. El código no
está en este repositorio.

Los releases los publica el flujo de GitHub Actions del repositorio del código.
**No subir ni editar nada a mano:** el programa instalado busca `latest.yml`
(Windows) y `latest-linux.yml` (Linux) en el último release, y un release armado
a mano puede dejar a todas las instalaciones sin actualizaciones.
